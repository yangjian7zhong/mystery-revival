# 神秘复苏模拟器

一个单文件网页文字生存模拟器。打开网页即玩，无需安装、无需注册、无需联网（AI 旁白为可选功能）。

**在线版**：https://yangjian7zhong.github.io/mystery-revival/

## 玩法

- 灵异复苏的都市里，你是刚开眼的驭鬼者：用理智与人性换取力量，在劫难值触顶前活到结局。
- 每回合在若干行动中选择一项；判定由「固定种子的确定性随机」得出 —— 同一个存档、同一回合、同一选项，结果永远一致，读档重试刷不出更好结果。
- 11 个结局、15 项成就、152 种机制事件、6 种鬼与 19 条线索、跨周目成长（记忆 / 遗物 / 教训）。
- 4 档难度 + 自定义参数（遭遇率 / 判定宽容 / 慈悲度）。

## 说明

- **游客模式**：直接开玩，使用内置程序化叙事。
- **账户模式**（可选）：在网页内创建本地账户后可绑定自己的 AI 接口（OpenAI 兼容 endpoint + model + key），为场景生成个性化旁白。
  - 账户与密钥**只保存在你自己的浏览器**里（本地 PBKDF2-SHA256 25 万次派生 + AES-GCM-256 加密），不会上传到任何服务器，本站也没有服务器。
  - AI 旁白**只影响文字描述，不影响任何判定与数值**，默认关闭。
  - 从 HTTPS 站点访问时，浏览器安全策略要求 AI 接口同样是 HTTPS（`http://localhost` / `http://127.0.0.1` 例外），且接口需允许跨域（CORS）。
